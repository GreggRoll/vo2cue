# Contributing to VO2Cue

VO2Cue is open source, and you are welcome to help improve it. Contributions can include bug fixes, features, accessibility improvements, documentation, and tests. Bug reports and ideas are welcome too.

## Getting started

1. Check [existing issues](https://github.com/GreggRoll/vo2cue/issues) or open an issue describing what you want to improve. Discuss larger changes with the maintainer before starting.
2. Fork the repository and create a branch for your change.
3. Follow the [build and test instructions](README.md#build-and-test) to set up the app.
4. Keep your change focused. Run the checks relevant to your change and include screenshots for visual changes when possible.
5. Open a [pull request](https://github.com/GreggRoll/vo2cue/pulls) explaining the problem, your solution, and how you verified it. Link any related issue and respond to review feedback.

You do not need to write code to help: clear documentation, reproducible bug reports, and accessibility feedback all make the app better.

## Free lifetime subscription

**Contributors receive a free lifetime subscription to VO2Cue for a successful merge request.** On GitHub, merge requests are called pull requests (PRs).

- A successful PR is one the maintainer has reviewed, accepted, and merged into this repository.
- Code, documentation, accessibility, and test contributions can qualify when accepted and merged.
- Opening a PR, reporting an issue, or suggesting an idea alone does not qualify; the contribution must be merged.
- After your PR is merged, leave a comment in that PR thread asking to arrange your free lifetime subscription. The maintainer will coordinate fulfillment with you. Do not post private account or payment information publicly.

The reward is a thank-you for helping improve VO2Cue. If you are unsure whether a proposed change is a good fit, discuss it in an issue before investing time in it.
